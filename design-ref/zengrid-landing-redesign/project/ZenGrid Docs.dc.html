Quick start

Get a virtualized grid rendering a million rows in under five minutes. All you need is a container element and your data.

1 · Install

terminal 
npm i @zengrid/core

2 · Mount your first grid

main.ts 
import { ZenGrid } from '@zengrid/core'

const grid = new ZenGrid(document.querySelector('#grid'), {
  data: rows,
  columns: [
    { field: 'name', header: 'Name' },
    { field: 'revenue', header: 'Revenue', type: 'number' },
  ],
  virtual: true,
})
tip With virtual: true, only visible rows are mounted — dataset size stops mattering to the DOM.

3 · Turn on interactions

Sorting, filtering, selection, and editing are single flags — each one exposes a typed API on the grid instance (grid.sort, grid.filter, grid.selection).

From here, head to Features to see each interaction live, or the API reference for every option.
