import { Badge } from '@astrojs/starlight/components';

Highlights for each release. For a capability-by-version overview, see the
[Feature Matrix](/feature-matrix/).

## v1.4.0 <Badge text="Latest" variant="success" />

- **New:** [Row Spanning](/features/row-spanning/) <Badge text="Enterprise" variant="caution" size="small" /> — merge cells vertically to group repeated values.
- Performance: faster re-layout when toggling themes.

## v1.3.1

- Fixes to scrollbar theming in dark mode.
- Stability improvements for very wide datasets.

## v1.2.0

- **New:** [Column Pinning](/features/columns/column-pinning/) <Badge text="Enterprise" variant="caution" size="small" /> — freeze columns to either edge.

## v1.0.0

- Initial release: [Virtual Scrolling](/features/virtual-scrolling/) <Badge text="Community" variant="success" size="small" />, sorting, keyboard navigation.
