## Introduction

Row selection highlights whole rows rather than individual cells — the right model
for a list you act on record-by-record (bulk delete, export the checked rows, open
a detail panel). Turn it on with `selectionType: 'row'`:

```ts
const grid = new Zengrid(mount, {
  columns,
  selectionType: 'row',
  enableMultiSelection: true,   // omit for single-row selection
  onSelectionChange: (ranges) => {
    // ranges are row spans in source coordinates
  },
});
```

Clicking a row selects it (and clicking it again clears it). With
`enableMultiSelection: true`, **ctrl/⌘-click** adds a row and **shift-click** takes
the contiguous run from the anchor. Every change fires `onSelectionChange` with the
selected row spans.

## The select-all header checkbox

Give a column a checkbox header and the grid renders a header checkbox that
selects or clears every row — the same `select-all` the API's `selectAll()` runs:

```ts
columns: [
  { field: 'name', header: { text: '', type: 'checkbox' }, width: 44 },
  // …
]
```

:::note[Row spans, not row lists]
`grid.selection.getRanges()` returns **ranges** — each with a `startRow`/`endRow`.
A shift-selected run of rows 3–7 is one range, not five. Expand them yourself, or
use `grid.selection.isRowSelected(row)` to test a single row.
:::

## Try it live

export const columns = `  columns: [
    { field: 'name',    header: 'Name',    width: 220 },
    { field: 'role',    header: 'Role',    width: 190 },
    { field: 'region',  header: 'Region',  width: 150 },
    { field: 'revenue', header: 'Revenue', width: 150, renderer: currency },
    { field: 'status',  header: 'Status',  width: 130, renderer: chips },
  ],`;

export const variants = [
  {
    id: 'single',
    label: 'Single row',
    hint: 'No enableMultiSelection — exactly one row at a time. Click a row to select it, click it again to clear. onSelectionChange logs each change to the console.',
    code: `// In scope: Zengrid, mount, rows, currency, chips, zg
// selectionType 'row' with no multi flag = one row at a time.
const grid = new Zengrid(mount, {
  rowCount: rows.length,
  rowHeight: 44,
  selectionType: 'row',
  onSelectionChange: (ranges) => console.log('selection:', ranges),
${columns}
});

grid.setData(rows);
`,
    controls: [
      { label: 'Selected row', action: "alert('selected row: ' + (grid.selection.getRanges()[0]?.startRow ?? 'none'))" },

  },
