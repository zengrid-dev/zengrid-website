## Introduction

Column spanning will let a cell stretch across two or more adjacent columns — for
example a section label that spans the full width of a group of columns.

:::note[Coming soon]
This is an upcoming Enterprise capability and isn't available yet as a
column-level option. See [Row Spanning](/features/row-spanning/) for the related
vertical feature.
:::
