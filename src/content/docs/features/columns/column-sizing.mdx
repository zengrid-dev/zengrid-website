## Introduction

Every column has a width and optional min/max constraints. Users can drag the
edge of a header to resize (on by default), and you can resize, auto-fit, or
constrain columns programmatically through `grid.columns`.

## Widths and constraints

Set widths per column in the definition. Constraints clamp both user drags and
programmatic resizes.

```ts
columns: [
  { field: 'name', header: 'Name', width: 240, minWidth: 120, maxWidth: 400 },
  { field: 'status', header: 'Status', width: 140, resizable: false },
]
```

A grid-level `colWidth` provides the fallback width for columns without an
explicit `width`.

## Resize behavior

Resizing is enabled by default. Tune it with `columnResize`, or turn it off with
`enableColumnResize: false`.

```ts
const grid = new Zengrid(el, {
  rowCount,
  colCount,
  rowHeight: 36,
  colWidth: 160,
  enableColumnResize: true,
  columnResize: {
    resizeZoneWidth: 6,     // px hit-zone on the column edge
    defaultMinWidth: 30,
    defaultMaxWidth: Infinity,
    showHandles: true,      // visible resize handles
    showPreview: true,      // preview line while dragging
    autoFitOnLoad: false,   // auto-fit all columns on first render
    autoFitSampleSize: 100, // rows sampled when auto-fitting
    autoFitPadding: 16,
    skipHeaderOnAutoSize: false,
  },
  columns,
});
```

## Programmatic sizing — `grid.columns`

```ts
interface ColumnApi {
  resize(col: number, width: number): void;
  autoFit(col: number): void;
  autoFitAll(): void;
  setConstraints(col: number, constraints: { minWidth: number; maxWidth: number }): void;
  updateResizeHandles(): void;
}
```

```ts
grid.columns.resize(0, 300);                       // set column 0 to 300px
grid.columns.autoFit(1);                            // fit column 1 to its content
grid.columns.autoFitAll();                          // fit every column
grid.columns.setConstraints(2, { minWidth: 80, maxWidth: 320 });
```

## Try it live

Each tab isolates one dimension of sizing. Edit the snippet — change a width, a
constraint, or the `columnResize` block and the grid re-renders. The
**Programmatic** tab adds buttons that drive `grid.columns` without touching the
code.

// width sets each column's starting size. minWidth/maxWidth clamp every drag
// AND every programmatic resize; resizable:false locks a column outright.

  rowCount: rows.length,
  rowHeight: 36,
  columns: [
    { field: 'name',    header: 'Name',    width: 240, minWidth: 140, maxWidth: 420 },
    { field: 'role',    header: 'Role',    width: 200 },
    { field: 'region',  header: 'Region',  width: 160 },

    { field: 'status',  header: 'Status',  width: 140, renderer: chips, resizable: false },
