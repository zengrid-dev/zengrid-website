ZenGrid renders only the rows you can see — a million-row dataset stays a handful
of DOM nodes. This guide gets a grid on screen fast.

## Install

<Tabs>
  <TabItem label="npm">`sh npm i @zengrid/core `</TabItem>
  <TabItem label="pnpm">`sh pnpm add @zengrid/core `</TabItem>
  <TabItem label="yarn">`sh yarn add @zengrid/core `</TabItem>
</Tabs>

## Your first grid

<Steps>
  1. Import the grid and its stylesheet.

     ```ts
     import { Grid } from '@zengrid/core';
     import '@zengrid/core/dist/styles.css';
     ```

  2. Create a grid against a mount element.

     ```ts
     const grid = new Grid(document.getElementById('app')!, {
       rowCount: 1_000_000,
       columns: [
         { field: 'name', header: 'Name', width: 240, sortable: true },
         { field: 'region', header: 'Region', width: 160 },
         { field: 'revenue', header: 'Revenue', width: 160 },
       ],
     });
     ```

  3. Feed it data and render.

     ```ts
     grid.setData(rows);
     grid.render();
     ```
</Steps>
