Highlights for each release. For a capability-by-version overview, see the
[Feature Matrix](/1.3/feature-matrix/).

## v1.3.1 <Badge text="Latest" variant="success" />

* Fixes to scrollbar theming in dark mode.
* Stability improvements for very wide datasets.

## v1.2.0

* **New:** [Column Pinning](/1.3/features/column-pinning/) <Badge text="Enterprise" variant="caution" size="small" /> — freeze columns to either edge.

## v1.0.0

* Initial release: [Virtual Scrolling](/1.3/features/virtual-scrolling/) <Badge text="Community" variant="success" size="small" />, sorting, keyboard navigation.
